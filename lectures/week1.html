3. What Is Python?

Python is a programming language.

A programming language allows us to give instructions to a computer.

Economists use Python to:

  • clean datasets
  • calculate economic indicators
  • create graphs
  • run regressions
  • build dashboards
  • forecast economic variables
  • build machine learning models
  • analyse text
  • automate repetitive work

You do not need to memorise Python.

You need to learn how to use it.

4. Why Economists Use Python

Economists increasingly work with data.

Governments, central banks, businesses, NGOs, research institutes, and international organisations use data to answer questions such as:

  • Is inflation increasing?
  • Are households becoming poorer?
  • Which firms are likely to grow?
  • Can we forecast demand?
  • Which regions need policy support?
  • What do news articles say about the economy?
  • Can AI help analyse large amounts of information?

Traditional economics gives us theory.

Data analytics helps us measure, test, predict, visualise, and communicate.

This course connects both.

5. What Is Google Colab?

Google Colab is a cloud-based coding environment.

It allows you to run Python directly in your browser.

This means:

  • no Python installation is required at the beginning
  • you can work from most computers
  • notebooks can be saved to Google Drive
  • notebooks can be shared using links

For the first few weeks, we will use Google Colab because it reduces technical problems.

11. Variables

A variable is a name used to store a value.

Example:

gdp_2023 = 100
gdp_2024 = 105

Here:

  • gdp_2023 stores the value 100
  • gdp_2024 stores the value 105

Variables allow us to organise calculations clearly.

12. Economic Calculation 1: GDP Growth

Formula

GDP Growth = [(GDP this year - GDP last year) / GDP last year] × 100

Python code

gdp_last_year = 1000
gdp_this_year = 1080

gdp_growth = ((gdp_this_year - gdp_last_year) / gdp_last_year) * 100

print(gdp_growth)

Interpretation

The economy grew by 8 percent.

  • Why do economists use percentage changes?
  • Why is percentage growth more useful than only looking at the absolute change?

14. Economic Calculation 2: Inflation Rate

Formula

Inflation Rate = [(CPI this year - CPI last year) / CPI last year] × 100

Python code

cpi_last_year = 200
cpi_this_year = 240

inflation_rate = ((cpi_this_year - cpi_last_year) / cpi_last_year) * 100

print(inflation_rate)

Interpretation

Prices increased by 20 percent.

15. Economic Calculation 3: Exchange Rate Depreciation

Formula

Depreciation = [(New exchange rate - Old exchange rate) / Old exchange rate] × 100

Python code

exchange_rate_old = 320
exchange_rate_new = 360

depreciation = ((exchange_rate_new - exchange_rate_old) / exchange_rate_old) * 100

print(depreciation)

Interpretation

The domestic currency depreciated by 12.5 percent.

16. Economic Calculation 4: Real Income

Formula

Real Income = Nominal Income / Price Index × 100

Python code

nominal_income = 100000
price_index = 125

real_income = (nominal_income / price_index) * 100

print(real_income)

Interpretation

Although nominal income is 100,000, real income is 80,000 in base-year prices.

17. What Is AI?

Artificial Intelligence, or AI, refers to computer systems that can perform tasks that usually require human intelligence.

Examples include:

  • answering questions
  • translating text
  • recognising images
  • writing summaries
  • identifying patterns
  • supporting decision-making

An AI tool can help summarise a central bank report.

But it may also make mistakes.

Therefore, economists must use AI critically.

AI can assist your thinking.

It should not replace your thinking.

18. What Is Machine Learning?

Machine learning is a type of AI.

It allows computers to learn patterns from data.

Instead of giving the computer every rule manually, we give it data and allow it to detect patterns.

Example:

Suppose we have household data with:

  • income
  • education
  • household size
  • location
  • employment status

A machine learning model may learn patterns that help predict whether a household is likely to be poor.

Important distinction:

Economics Machine Learning
Often focuses on explanation and causality Often focuses on prediction
Asks why something happens Asks what is likely to happen
Uses theory heavily Uses patterns in data heavily

This difference matters throughout the course.

19. Difference Between Python, Excel, Stata, AI, and ML

Tool/Concept What it does
Excel Spreadsheet-based calculations and basic analysis
Stata Statistical software widely used in economics
Python General-purpose programming language for data analysis and automation
AI Systems that perform tasks associated with human intelligence
Machine Learning Methods that learn patterns from data for prediction or classification

Python does not replace economic thinking.

It expands what economists can do with data.

22. Common Beginner Errors

Problem 1: Missing quotation marks

Wrong:

print(Hello Economics)

Correct:

print("Hello Economics")

Problem 2: Using commas in numbers

Wrong:

gdp = 1,000

Better:

gdp = 1000

Problem 3: Wrong multiplication symbol

Wrong:

growth = value x 100

Correct:

growth = value * 100

Problem 4: Forgetting to run the code cell

In Colab, press:

Shift + Enter

  • produce wrong calculations
  • give weak economic interpretations
