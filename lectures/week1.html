Week 1 — Orientation: Python, AI, and Data Analytics

Welcome to:

ECN 4199 — Industrial Data Analytics

This first week is NOT about advanced programming.

  • learning how to work with Google Colab

  • explain why economists use Python
  • understand what Google Colab is
  • open and save a Colab notebook

  • understand basic AI and machine learning concepts
  • submit a notebook link properly

3. What Is Python?

Python is a programming language.

A programming language allows us to give instructions to a computer.

Economists increasingly use Python to:

  • clean datasets
  • calculate economic indicators
  • create visualizations
  • run regressions
  • build dashboards
  • forecast economic variables
  • build machine learning models
  • analyze text
  • automate repetitive tasks

You do NOT need to memorize Python.

You need to learn how to use it practically.

4. Why Economists Use Python

Economists increasingly work with large amounts of data.

Governments, firms, central banks, NGOs, and international organizations use data to answer questions such as:

  • Is inflation increasing?
  • Are households becoming poorer?
  • Which firms are likely to grow?
  • Can we forecast demand?
  • Which regions need policy support?
  • What do news articles say about the economy?
  • Can AI help analyze economic information?

Traditional economics gives us theory.

Data analytics helps us:

  • measure
  • test
  • predict
  • visualize
  • communicate

This course connects economics with modern analytical tools.

5. What Is Google Colab?

Google Colab is a cloud-based coding environment.

It allows students to run Python directly through a web browser.

This means:

  • no Python installation is initially required
  • coding can be done from most computers
  • notebooks can be saved to Google Drive
  • notebooks can be shared using links

For the first few weeks, the course will primarily use Google Colab to minimize technical barriers.

8. Code Cells and Text Cells

Good notebooks should contain BOTH:

  • interpretation

12. Economic Calculation 1 — GDP Growth

Formula

GDP Growth = [(GDP this year - GDP last year) / GDP last year] × 100

Python Code

gdp_last_year = 1000
gdp_this_year = 1080

gdp_growth = ((gdp_this_year - gdp_last_year) / gdp_last_year) * 100

print(gdp_growth)

Interpretation

The economy grew by:

8 percent

  • Why do economists use percentage changes?
  • Why is percentage growth more informative than absolute changes?

14. Economic Calculation 2 — Inflation Rate

Formula

Inflation Rate = [(CPI this year - CPI last year) / CPI last year] × 100

Python Code

cpi_last_year = 200
cpi_this_year = 240

inflation_rate = ((cpi_this_year - cpi_last_year) / cpi_last_year) * 100

print(inflation_rate)

Interpretation

Prices increased by:

20 percent

15. Economic Calculation 3 — Exchange Rate Depreciation

Formula

Depreciation = [(New exchange rate - Old exchange rate) / Old exchange rate] × 100

Python Code

exchange_rate_old = 320
exchange_rate_new = 360

depreciation = ((exchange_rate_new - exchange_rate_old) / exchange_rate_old) * 100

print(depreciation)

Interpretation

The domestic currency depreciated by:

12.5 percent

16. Economic Calculation 4 — Real Income

Formula

Real Income = Nominal Income / Price Index × 100

Python Code

nominal_income = 100000
price_index = 125

real_income = (nominal_income / price_index) * 100

print(real_income)

Interpretation

Although nominal income is:

100,000

real income is:

80,000

in base-year prices.

17. What Is Artificial Intelligence (AI)?

Artificial Intelligence refers to computer systems capable of performing tasks typically associated with human intelligence.

Examples include:

  • answering questions
  • translating text
  • summarizing information
  • recognizing patterns
  • generating code
  • supporting decision-making

AI tools can support economists.

However, AI systems can also:

  • make mistakes
  • hallucinate information
  • misunderstand context
  • produce weak interpretations

Therefore:

AI should support thinking — not replace thinking.

18. What Is Machine Learning?

Machine learning is a branch of AI.

Machine learning systems learn patterns from data.

Instead of manually specifying every rule, we provide data and allow the model to identify relationships.

Example:

A machine learning system may use:

  • income
  • education
  • employment
  • location
  • household size

to predict poverty risk.

Important Distinction

Economics Machine Learning
Often emphasizes causality Often emphasizes prediction
Asks why something happens Asks what is likely to happen
Theory-driven Pattern-driven

Understanding this distinction is extremely important throughout the course.

19. Difference Between Python, Excel, Stata, AI, and ML

Tool/Concept Purpose
Excel Spreadsheet calculations
Stata Statistical analysis software
Python General-purpose programming language
AI Systems performing human-like tasks
Machine Learning Systems learning patterns from data

Python does NOT replace economics.

It expands what economists can do computationally.

Problem 2 — Using Commas in Numbers

Wrong:

Correct:

gdp = 1000

Problem 3 — Wrong Multiplication Symbol

Wrong:

Correct:

growth = value * 100
