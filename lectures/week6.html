Week 6 — Building Interactive Economic Dashboards with Plotly

Week 6 — Interactive Dashboards and Data Storytelling for Economics

Weeks 1–5 focused on:

  • Python fundamentals
  • data handling
  • descriptive statistics
  • visualization

Now students move from:

creating graphs

to:

building analytical systems

This week introduces:

  • interactive dashboards
  • dynamic visualization
  • dashboard logic
  • user interaction
  • exploratory analysis
  • data storytelling

Modern economists increasingly communicate through:

  • dashboards
  • interactive reports
  • web applications
  • real-time monitoring systems

This week is a major transition.

1. Learning Objectives

By the end of this week, students should be able to:

  • explain what dashboards are
  • distinguish static vs interactive visualization
  • build interactive Plotly graphs
  • create dashboard layouts
  • add hover information
  • design multi-chart dashboards
  • communicate economic insights interactively

2. What Is a Dashboard?

A dashboard is:

a visual interface that organizes and displays important information for decision-making

Dashboards combine:

  • graphs
  • indicators
  • summaries
  • tables
  • filters
  • interactive elements

Examples of Economic Dashboards

Economists use dashboards for:

  • inflation monitoring
  • exchange rate tracking
  • labour market analysis
  • trade monitoring
  • financial market surveillance
  • poverty mapping

Important Idea

A dashboard is NOT:

many graphs on one page

A good dashboard:

  • answers questions
  • guides interpretation
  • highlights patterns
  • supports decisions

3. Why Dashboards Matter in Economics

Modern economics increasingly involves:

  • large datasets
  • multiple indicators
  • real-time information
  • policy communication

Dashboards help:

  • policymakers
  • researchers
  • firms
  • journalists
  • the public

understand complex information quickly.

Example

A central bank dashboard may display:

  • inflation
  • reserves
  • exchange rates
  • interest rates
  • unemployment
  • money supply

within one integrated system.

Critical Lesson

Visualization is NOT decoration.

Visualization is:

economic communication

4. Static vs Interactive Visualization

Traditional graphs are static.

Interactive graphs allow users to:

  • zoom
  • hover
  • filter
  • explore relationships
  • inspect exact values

Static Graph Example

plt.plot(data["Year"], data["Inflation"])

Interactive Graph Example

fig = px.line(data,
              x="Year",
              y="Inflation")

fig.show()

Advantages of Interactive Graphs

Feature Benefit
Hovering Shows exact values
Zooming Explore details
Interactivity Better exploration
Dynamic filtering Flexible analysis

5. Introduction to Plotly

Plotly is one of the most widely used interactive visualization libraries.

It allows us to create:

  • interactive charts
  • dashboards
  • web-ready visualizations

Import Plotly

import plotly.express as px

Basic Interactive Line Graph

fig = px.line(data,
              x="Year",
              y="Inflation")

fig.show()

What Happens?

Students can:

  • hover over values
  • zoom into periods
  • interact with the graph

6. Building Interactive Line Graphs

Line graphs are ideal for:

  • inflation
  • GDP growth
  • unemployment
  • exchange rates
  • reserves

Example

fig = px.line(data,
              x="Year",
              y="Inflation",
              title="Inflation Trends in Sri Lanka")

fig.show()

Adding Multiple Variables

fig = px.line(data,
              x="Year",
              y=["Inflation", "GDP_Growth"])

fig.show()

Interpretation Questions

Ask:

  • Which variable is more volatile?
  • Do variables move together?
  • When do structural breaks occur?

7. Building Interactive Bar Charts

Bar charts are useful for:

  • comparing regions
  • comparing sectors
  • comparing years
  • comparing categories

Example

fig = px.bar(data,
             x="Year",
             y="GDP_Growth")

fig.show()

Example with Colors

fig = px.bar(data,
             x="Year",
             y="GDP_Growth",
             color="GDP_Growth")

fig.show()

Important Lesson

Color should support interpretation.

Do NOT use colors randomly.

8. Interactive Scatter Plots

Scatter plots help explore relationships interactively.

Example

fig = px.scatter(data,
                 x="Inflation",
                 y="Exchange_Rate_Change")

fig.show()

Adding Labels

fig = px.scatter(data,
                 x="Inflation",
                 y="Exchange_Rate_Change",
                 hover_name="Year")

fig.show()

Why This Matters

Users can:

  • identify outliers
  • inspect specific years
  • explore relationships dynamically

9. Adding Hover Information

Hover information improves analytical depth.

Example

fig = px.line(data,
              x="Year",
              y="Inflation",
              hover_data=["GDP_Growth",
                          "Exchange_Rate"])

fig.show()

Why Hover Information Matters

Users can inspect:

  • exact values
  • related indicators
  • contextual information

10. Dashboard Design Principles

Most beginner dashboards are terrible.

Why?

Because they:

  • overload information
  • lack structure
  • lack hierarchy
  • prioritize appearance over analysis

Good Dashboard Principles

Principle Meaning
Simplicity Avoid clutter
Hierarchy Important information first
Consistency Similar styles
Readability Clear labels
Relevance Only useful graphs

Important Warning

More charts do NOT mean:

better analysis

11. Multi-Chart Dashboards

Dashboards often combine multiple visualizations.

Example Dashboard Structure

Section Content
Top panel Key indicators
Middle panel Trends
Bottom panel Relationships

Import Dashboard Tools

from plotly.subplots import make_subplots
import plotly.graph_objects as go

Simple Subplot Example

fig = make_subplots(rows=2,
                    cols=1)

fig.add_trace(
    go.Scatter(x=data["Year"],
               y=data["Inflation"]),
    row=1,
    col=1
)

fig.add_trace(
    go.Scatter(x=data["Year"],
               y=data["GDP_Growth"]),
    row=2,
    col=1
)

fig.show()

12. Storytelling with Dashboards

Dashboards should guide interpretation.

A dashboard should answer:

  • What happened?
  • Why does it matter?
  • What patterns exist?
  • What should decision-makers notice?

Weak Dashboard

Many disconnected graphs

Strong Dashboard

A coherent analytical story

Example Narrative

Inflation accelerated sharply after 2021, coinciding with severe exchange rate depreciation and negative GDP growth.

Critical Lesson

Data storytelling is:

  • analytical
  • strategic
  • interpretive

NOT decorative.

22. Common Errors

Problem 1 — Too Many Charts

More graphs do NOT improve analysis.

Simplify.

Problem 2 — Missing Titles

Every graph must explain:

  • what is shown
  • units
  • variables

Problem 3 — Misleading Scales

Axis scaling can distort interpretation.

Problem 4 — Random Colors

Colors should communicate meaning.

Problem 5 — No Interpretation

A dashboard without interpretation is incomplete analysis.

23. AI Reflection Question

AI can automatically generate dashboards.

However:

  • AI may prioritize aesthetics over analysis
  • AI may ignore economic relevance
  • AI may produce misleading visual structures

Reflection question:

Why must economists think critically about dashboard design even when AI tools automate visualization?
