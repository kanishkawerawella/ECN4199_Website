Week 2 — Working with Data in Python

Introduction

In Week 1, we learned how to use Python as a calculator and how to execute simple commands.

This week, we begin working with the most important asset in modern economics:

DATA

Every day economists use data to answer questions such as:

  • Why are some people unemployed?
  • What determines wages?
  • Why does inflation increase?
  • Which districts experience higher poverty?
  • How does education affect earnings?
  • How does technology influence productivity?

Regardless of whether you become:

  • an economist
  • policy analyst
  • researcher
  • consultant
  • banker
  • data analyst

your ability to work with data will become increasingly important.

For this reason, Week 2 focuses on understanding how Python stores and organizes data.

Everything we do later in the course:

  • data visualization
  • dashboards
  • forecasting
  • machine learning
  • artificial intelligence

depends on concepts introduced this week.

1. Why Data Matters

Economics has undergone a major transformation over the last several decades.

Historically, economists relied heavily on:

  • theory
  • intuition
  • logical reasoning

Today, economics is increasingly data-driven.

When policymakers ask:

Did a policy work?

they usually expect evidence.

When firms ask:

Should we invest?

they expect evidence.

When international organizations ask:

Has poverty fallen?

they expect evidence.

The answer usually comes from data.

Data allows economists to:

  • test theories
  • evaluate policies
  • forecast outcomes
  • identify patterns
  • support decision-making

Without data, economics becomes speculation.

With data, economics becomes evidence-based.

2. What Is Data?

Data refers to information collected about people, organizations, events, or objects.

Examples include:

Person Age Wage
A 25 45000
B 34 70000
C 52 95000

This table contains data.

To work with data effectively, we need to understand several concepts.

Observation

An observation is the unit being studied.

Examples include:

  • a person
  • a household
  • a firm
  • a district
  • a country

In the example above:

Each row is an observation.

Variable

A variable is a characteristic being measured.

Examples:

  • age
  • wage
  • education
  • employment status
  • inflation
  • GDP growth

In the example above:

Each column is a variable.

Dataset

A dataset is simply:

A collection of observations and variables.

This definition remains the same whether you use:

  • Excel
  • Stata
  • SPSS
  • R
  • Python

3. How Computers Think About Data

Humans naturally understand tables.

Computers do not.

Humans see:

Year Inflation
2020 4.6
2021 6.0
2022 46.4

A computer sees:

2020
4.6

2021
6.0

2022
46.4

Computers require information to be organized using specific structures.

Python provides several structures for storing information.

The simplest of these structures is the variable.

4. Variables

A variable stores a value.

Think of a variable as a labelled container.

Example:

inflation_2022 = 46.4

Here:

inflation_2022

is the name.

And:

46.4

is the value.

Displaying Variables

inflation_2022 = 46.4

print(inflation_2022)

Output:

46.4

Economic Examples

country = "Sri Lanka"

exchange_rate = 360

gdp_growth = -7.8

population = 22000000

These variables store different kinds of information.

Why Variables Matter

Variables allow us to:

  • store information
  • reuse information
  • perform calculations
  • organize data

Without variables, programming would become extremely difficult.

Example: Real Wage Change

Suppose inflation increased by:

inflation = 46.4

while wages increased by:

wage_growth = 20

Then:

real_wage_change = wage_growth - inflation

print(real_wage_change)

Output:

-26.4

Interpretation:

Although nominal wages increased, purchasing power declined.

5. Data Types

Not all information is stored in the same way.

Python uses different data types.

Understanding data types is important because different types support different operations.

Integer

Integers are whole numbers.

Examples:

age = 25

children = 3

districts = 25

Float

Floats contain decimal points.

Examples:

inflation = 46.4

gdp_growth = -7.8

interest_rate = 8.5

String

Strings contain text.

Examples:

country = "Sri Lanka"

district = "Colombo"

sector = "Services"

Boolean

Booleans contain only:

True
False

Examples:

employed = True

internet_access = False

Checking Data Types

Python can tell us the type of a variable.

Example:

inflation = 46.4

type(inflation)

Output:

float

Try:

type(country)

type(age)

type(employed)

Why Data Types Matter

Suppose:

age = 25

age + 10

works perfectly.

But:

country = "Sri Lanka"

country + 10

produces an error.

Different data types behave differently.

Understanding data types helps us avoid mistakes.

6. Lists

Economists rarely work with single observations.

Usually we work with many observations.

Example:

Year Inflation
2020 4.6
2021 6.0
2022 46.4

Rather than storing each value separately:

inflation_2020 = 4.6

inflation_2021 = 6.0

inflation_2022 = 46.4

we can store them together.

This is called a list.

inflation = [4.6, 6.0, 46.4]

Why Lists Matter

Lists allow us to store multiple observations inside a single object.

Think of a list as a vector.

Students familiar with statistics can think:

List = Vector

Displaying Lists

inflation = [4.6, 6.0, 46.4]

print(inflation)

Output:

[4.6, 6.0, 46.4]

Multiple Lists

year = [2020, 2021, 2022]

inflation = [4.6, 6.0, 46.4]

gdp_growth = [-3.6, 3.7, -7.8]

We now have multiple vectors.

This is the foundation of a dataset.

Accessing Individual Elements

Python uses indexing.

inflation[0]

Output:

4.6
inflation[1]

Output:

6.0
inflation[2]

Output:

46.4

Important Rule

Python starts counting from:

0

NOT:

1

This is one of the most common beginner mistakes.

Part 2 — Libraries, Pandas, and DataFrames

7. Why We Need More Than Python

So far we have used basic Python.

For example:

inflation = [4.6, 6.0, 46.4]

print(inflation)

This works perfectly.

However, imagine that you are working with:

  • 1000 individuals
  • 20 variables
  • 50,000 observations
  • multiple datasets

Could we realistically analyze such datasets using only basic Python?

The answer is:

Not efficiently.

This is where libraries become important.

8. What Is a Library?

A library is a collection of pre-written code that has been developed by other programmers.

Instead of writing everything ourselves, we can use tools that already exist.

Think of a library as a toolbox.

A carpenter does not manufacture every tool before building a table.

Similarly, a data analyst does not write every function from scratch.

Instead, analysts use libraries.

Everyday Analogy

Imagine that you want to build a house.

You could:

Option 1

Manufacture every brick,
every nail,
every screw,
every window yourself.

Or:

Option 2

Purchase tools and materials that already exist.

Most people choose Option 2.

Libraries work in exactly the same way.

Why Libraries Matter

Libraries allow us to:

  • save time
  • reduce errors
  • use tested code
  • perform complex tasks easily
  • focus on analysis rather than programming

Without libraries, modern data analytics would be extremely difficult.

Python’s Strength

One reason Python became so popular is its enormous collection of libraries.

There are libraries for:

  • data analysis
  • econometrics
  • machine learning
  • artificial intelligence
  • forecasting
  • visualization
  • web applications
  • finance
  • text analytics

9. What Is Pandas?

Pandas is a library designed specifically for working with datasets.

Think about the software you already know.

Pandas performs many tasks similar to:

  • Excel
  • Stata
  • SPSS

However, it also allows automation and scalability.

What Can Pandas Do?

Pandas allows us to:

  • import datasets
  • clean data
  • rename variables
  • sort observations
  • filter observations
  • create new variables
  • merge datasets
  • reshape data
  • summarize information
  • prepare data for machine learning

In practice:

Most data analytics projects begin with Pandas.

Why Is It Called Pandas?

The name comes from:

Panel Data

and

Python Data Analysis

The library was originally designed to make handling structured datasets easier.

Importing Pandas

Before using Pandas, we must import it.

import pandas as pd

Understanding This Command

import pandas as pd

means:

Import the Pandas library
and give it the shorter nickname "pd".

Why Use “pd”?

Without an alias:

pandas.DataFrame()

With an alias:

pd.DataFrame()

The second option is shorter and easier to read.

Almost every Python analyst uses:

import pandas as pd

10. What Is a DataFrame?

A DataFrame is the most important object in Pandas.

Think of a DataFrame as:

A dataset inside Python.

DataFrame Analogy

Software Dataset Object
Excel Worksheet
Stata Dataset
SPSS Data File
Pandas DataFrame

Why DataFrames Matter

Suppose you have:

  • 1000 people
  • 20 variables

Storing them as individual lists would become difficult.

Instead, we store everything inside one DataFrame.

Creating Our First Dataset

Let’s create a small dataset manually.

import pandas as pd

data = pd.DataFrame({
    "Year":[2020,2021,2022],
    "Inflation":[4.6,6.0,46.4],
    "GDP_Growth":[-3.6,3.7,-7.8]
})

data

Understanding What Happened

We created:

Variable 1

Year

Variable 2

Inflation

Variable 3

GDP_Growth

Each variable contains a list of observations.

Pandas combines them into a dataset.

Rows and Columns

A DataFrame contains:

Rows

Observations

Columns

Variables

Exactly as in econometrics.

Economic Interpretation

Observe:

Year Inflation GDP Growth
2020 4.6 -3.6
2021 6.0 3.7
2022 46.4 -7.8

Question:

What happened in 2022?

Students should immediately notice:

  • inflation increased sharply
  • growth became negative

Notice:

We are already doing analysis,
not merely coding.

Creating a Labour Market Dataset

Suppose we have:

Person Age Wage
A 25 45000
B 35 65000
C 50 90000

Create it in Python:

labour = pd.DataFrame({
    "Age":[25,35,50],

labour

Why This Is Powerful

Imagine:

Instead of:

3 observations

you have:

300,000 observations

The code changes very little.

This scalability is one of the major advantages of Python.

Viewing Variable Names

Sometimes we forget variable names.

Pandas can show them.

labour.columns

Output:

Age
Monthly_Wage

Viewing Dataset Shape

labour.shape

Output:

(3,2)

Interpretation:

3 observations
2 variables

Why Shape Is Useful

Before beginning analysis, analysts often ask:

  • How many observations?
  • How many variables?

Shape immediately answers both questions.

Common Beginner Mistakes

Missing Comma

Wrong:

"Age":[25,35,50]
"Monthly_Wage":[45000,65000,90000]

Correct:

"Age":[25,35,50],
"Monthly_Wage":[45000,65000,90000]

Unequal Length Lists

Wrong:

pd.DataFrame({
"Age":[25,35,50],
"Wage":[45000,65000]
})

Every column must contain the same number of observations.

Forgetting Pandas Import

Wrong:

pd.DataFrame()

without:

import pandas as pd

Always import Pandas first.

12. Common Data File Formats

Data can be stored in many formats.

As analysts, we should understand the most common file types.

CSV Files

CSV stands for:

Comma Separated Values

Example:

Year,Inflation,GDP_Growth
2020,4.6,-3.6
2021,6.0,3.7
2022,46.4,-7.8

Advantages:

  • simple
  • universal
  • lightweight
  • widely used

Disadvantages:

  • cannot store formatting
  • cannot store formulas
  • cannot store multiple sheets

Excel Files

Extension:

.xlsx

Examples:

  • financial reports
  • survey datasets
  • business records

Advantages:

  • user friendly
  • supports multiple sheets
  • supports formulas

Disadvantages:

  • large files become slow
  • less suitable for reproducible analysis

Stata Files

Extension:

.dta

Common in:

  • economics
  • development economics
  • labour economics

Advantages:

  • variable labels
  • value labels
  • survey settings

Disadvantages:

  • requires specialized software

SPSS Files

Extension:

.sav

Common in:

  • social sciences
  • psychology
  • survey research

Other Formats

Modern analysts also encounter:

  • JSON
  • Parquet
  • SQL databases
  • APIs
  • Cloud databases

These will become increasingly important as datasets become larger.

13. Importing Data into Python

The command depends on the file type.

Importing a CSV File

import pandas as pd

data = pd.read_csv("data.csv")

Importing an Excel File

import pandas as pd

data = pd.read_excel("data.xlsx")

Importing a Stata File

import pandas as pd

data = pd.read_stata("data.dta")

Importing an SPSS File

import pandas as pd

data = pd.read_spss("data.sav")

Important Observation

Notice something interesting.

Only one part changes:

read_csv()

read_excel()

read_stata()

read_spss()

Everything else remains the same.

Look at the dataset.

100,000 observations

First 10 observations

data.tail()

Last 5 observations

  • duplicate records
  • data entry mistakes

tail() helps identify such issues.

  • standard deviation

Always interpret.

Do not simply produce output.
