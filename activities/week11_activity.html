Task 2 — Load and Visualize Time Series Data

Objective

Visualize inflation over time.

Instructions

Load the dataset and create line graph.

Expected Structure

import pandas as pd
import matplotlib.pyplot as plt

data = pd.read_csv("inflation_timeseries.csv")

plt.figure(figsize=(10,5))

plt.plot(data["Date"],
         data["Inflation"])

plt.title("Inflation Over Time")
plt.xlabel("Date")
plt.ylabel("Inflation")

plt.show()

Questions

Question 1

Does the series show an upward or downward trend?

Question 2

Question 3

Task 3 — Create Moving Average

Objective

Smooth short-run fluctuations.

Instructions

Create a 3-period moving average.

Example Structure

data["MA_3"] = data["Inflation"].rolling(window=3).mean()

Visualize Actual and Moving Average

plt.plot(data["Inflation"],
         label="Actual")

plt.plot(data["MA_3"],
         label="Moving Average")

plt.legend()

plt.show()

Task 5 — Estimate Forecasting Model

Objective

Estimate simple ARIMA model.

Instructions

Estimate ARIMA forecasting model.

Example Structure

from statsmodels.tsa.arima.model import ARIMA

model = ARIMA(train["Inflation"],
              order=(1,1,1))

model_fit = model.fit()

Generate Forecast

forecast = model_fit.forecast(steps=12)

Common Errors

Problem 1 — Random Train-Test Splits

Time series forecasting must preserve chronological order.

Problem 2 — Blind Trust in Forecasts

Forecasts are uncertain estimates, not certainty.

Problem 3 — Ignoring Structural Breaks

Forecasting models often fail during:

  • crises
  • wars
  • pandemics
  • policy regime changes

Problem 4 — Overcomplicated Models

Complex models may overfit historical patterns.

Problem 5 — Misinterpreting Low Forecast Error

Good historical performance does NOT guarantee future success.
