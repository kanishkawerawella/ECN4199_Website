Task 1 — Variables and Data Types

Objective

Create and understand variables.

Instructions

Create variables for:

  • inflation
  • GDP growth
  • exchange rate
  • country name

Use appropriate data types.

Example Structure

inflation = 46.4
country = "Sri Lanka"

Questions

integer

?

Task 2 — Lists and Economic Data

Objective

Instructions

Create a list containing GDP growth rates for four years.

Example:

gdp_growth = [3.5, 5.2, -7.8, 2.1]

Tasks

Calculate:

  • average GDP growth
  • maximum GDP growth
  • minimum GDP growth

Questions

Question 1

Question 2

Why are lists useful for economists?

Task 3 — Conditional Logic

Objective

Instructions

Write conditional logic using the following rules:

Inflation Rate Classification
Below 5 Low inflation
Between 5 and 15 Moderate inflation
Above 15 High inflation

Example Structure

inflation = 12

Question

Why is conditional logic important in economics and policy analysis?

Common Errors

Problem 1 — Indentation Errors

Wrong:

if inflation > 10:
print("High inflation")

Correct:

if inflation > 10:
    print("High inflation")

Problem 2 — Forgetting Colon

Wrong:

if inflation > 10

Correct:

if inflation > 10:

Problem 3 — Confusing = and ==

= assigns value.

== checks equality.

Problem 4 — Undefined Variables
