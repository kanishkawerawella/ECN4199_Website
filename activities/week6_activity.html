Week 6 Assignment — Build an Economic Dashboard

Week 6 Assignment — Build an Economic Dashboard

Item Details
Week Week 6
Topic Interactive Dashboards and Data Storytelling
Marks 5 Marks
Duration 1 Hour
Submission Completed Google Colab notebook link

Purpose

This assignment checks whether you can communicate economic evidence clearly using an interactive dashboard.

Your dashboard should not be decorative. It should help a reader understand the main macroeconomic pattern identified in Week 5.

This assignment builds directly from:

Previous Week Contribution to Week 6
Week 4 Prepared dataset and analytical variables
Week 5 Evidence, graphs, correlation, and interpretation
Week 6 Dashboard design and data storytelling

Materials

Plotly Guide Open Plotly Python Guide

File -> Save a copy in Drive

Week06_IndexNumber_Name.ipynb

Required Setup

Your notebook should load the dataset and recreate the Week 4 prepared variables:

import pandas as pd
import plotly.express as px
from plotly.subplots import make_subplots
import plotly.graph_objects as go

url = "https://raw.githubusercontent.com/kanishkawerawella/ECN4199_Website/main/data/sri_lanka_macro.csv"
data = pd.read_csv(url)

data["Exchange_Rate_Change"] = data["Exchange_Rate"].pct_change() * 100
data["Recession"] = data["GDP_Growth"] < 0
data["Low_Reserves"] = data["Reserves"] < 4000

Also recreate Inflation_Category using the Week 4 classification rule.

Task 1 — Dashboard Question and Audience

Write one dashboard question.

Example:

How did Sri Lanka's macroeconomic conditions change across the period?

Then identify:

  1. intended audience
  2. three indicators used in the dashboard
  3. why each indicator matters
  4. what the reader should notice first

Marks: 1

Task 2 — Interactive Charts

Create three interactive Plotly charts:

Chart Required Content
Line chart Inflation over time with useful hover data
Bar chart GDP growth by year, showing recession years
Scatter plot Inflation and exchange rate change, with year in hover information

Each chart must include:

  • meaningful title
  • readable labels
  • appropriate use of color
  • hover information where useful
  • one interpretation sentence

Marks: 1

Task 3 — Multi-Panel Dashboard

Create one multi-panel dashboard using Plotly subplots.

Your dashboard must include at least three indicators.

Suggested structure:

Panel Indicator
Top Inflation
Middle GDP growth
Bottom Exchange rate or reserves

Your dashboard must include:

  • clear title
  • coherent order of panels
  • readable layout
  • no unnecessary visual clutter

Marks: 1

Task 4 — Dashboard Design Review

Write 100-150 words evaluating your dashboard design.

Your review must mention:

  • the dashboard question
  • what the reader should notice first
  • why you selected these charts
  • how color or hover information helps interpretation
  • one limitation of the dashboard

Marks: 1

Task 5 — Dashboard Story

Write a final dashboard story of 150-220 words.

Your story must include:

  • one main claim
  • evidence from at least two indicators
  • economic meaning
  • one caution that the dashboard is descriptive, not causal
  • one sentence identifying what should be investigated next

Marks: 1

Marking Rubric

Criterion Mark
Dashboard question, audience, and indicators are clear 1
Interactive charts are complete, readable, and purposeful 1
Multi-panel dashboard is coherent and uncluttered 1
Design review is thoughtful and specific 1
Dashboard story is evidence-based, cautious, and policy-relevant 1

Submission Checklist

Before submitting, make sure:

  • all charts display correctly
  • the dashboard has a clear title
  • chart labels are readable
  • interpretation is written in your own words
  • the final story uses numerical evidence
  • the final story includes a caution statement
  • sharing is set to Anyone with the link -> Viewer
