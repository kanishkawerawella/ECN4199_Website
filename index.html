ECN 4199 — Industrial Data Analytics

Welcome to ECN 4199

Welcome to the course website for ECN 4199: Industrial Data Analytics.

This course introduces students to modern computational and analytical tools increasingly used in:

  • economics
  • business analytics
  • policy analysis
  • finance
  • industry research
  • AI-assisted decision systems

The course is specifically designed for students with little or no prior programming experience.

You are not expected to become a computer scientist.

You are expected to become an economist who can:

  • work confidently with data
  • think computationally
  • interpret analytical outputs critically
  • communicate evidence effectively
  • use AI systems responsibly

What You Will Learn

Throughout this course, students will gain practical exposure to:

  • Python programming
  • data analytics workflows
  • data visualization
  • regression analysis
  • machine learning fundamentals
  • forecasting and time series analytics
  • clustering and segmentation
  • dashboard development
  • NLP and text analytics
  • generative AI tools for analytics

The course emphasizes:

  • hands-on learning
  • interpretation
  • analytical reasoning
  • reproducible workflows
  • real-world applications

Course Learning Progression

Weeks Main Focus
Weeks 1–3 Python foundations and computational thinking
Weeks 4–6 Data handling, visualization, and dashboards
Weeks 7–9 Regression, prediction, and machine learning
Weeks 10–11 Clustering and forecasting
Week 12 NLP, AI, and text analytics
Week 13 Integrated analytics project

How to Use This Website

This website serves as the central learning platform for the course.

Students are expected to use the website continuously throughout the semester.

Weekly Learning Workflow

Each week, students should:

  1. Review the weekly lesson materials
  2. Open the live coding notebook
  3. Follow the lecture demonstrations
  4. Complete the in-class activity
  5. Submit the required weekly task

During Lecture Sessions

Students will actively use:

  • this course website
  • Google Colab notebooks
  • datasets provided through the course
  • interactive coding exercises
  • visualization and analytics tools

Outside Lecture Sessions

Students are encouraged to:

  • revisit coding notebooks
  • practice Python independently
  • explore additional datasets
  • review lecture materials
  • experiment with analytical techniques
  • improve interpretation and communication skills

Evaluation Structure

Assessment in this course emphasizes:

  • practical analytical thinking
  • computational skills
  • interpretation
  • problem solving
  • continuous engagement
  • real-world application

Assessment Breakdown

Component Weight
Weekly In-Class Activities (13 × 5 Marks) 65 Marks
Final Analytics Project 35 Marks
Total 100 Marks

Weekly In-Class Activities

Each week, students will complete a practical activity during the lecture session.

Activities may include:

  • coding exercises
  • visualization tasks
  • regression exercises
  • machine learning applications
  • forecasting tasks
  • interpretation exercises
  • NLP and AI activities

Each weekly activity carries:

5 Marks

Across 13 weeks, the total contribution becomes:

65 Marks

These activities are designed to promote:

  • continuous learning
  • active engagement
  • practical analytical experience
  • computational confidence

Final Analytics Project

Students will complete an individual final analytics project carrying:

35 Marks

The final project allows students to apply analytical methods learned throughout the course to a real-world economic, business, or policy problem.

Detailed guidelines are available under the:

Final Project

tab.

Important Course Philosophy

This course focuses on:

  • analytical thinking
  • interpretation
  • computational reasoning
  • evidence-based analysis
  • responsible use of AI systems

The objective is not memorizing code.

The objective is learning how to:

  • solve problems with data
  • interpret evidence critically
  • communicate findings effectively
  • evaluate uncertainty
  • use AI responsibly and ethically

Recommended Starting Point

Students should begin with:

  1. Reviewing the Course Roadmap
  2. Opening the Week 1 materials
  3. Accessing the Week 1 live notebook
  4. Completing the Week 1 activity

Final Note

Modern economics increasingly operates within environments shaped by:

  • data
  • algorithms
  • automation
  • machine learning
  • AI-assisted systems

This course is designed to help students develop the analytical and computational foundations necessary to engage critically and effectively with this rapidly changing landscape.
